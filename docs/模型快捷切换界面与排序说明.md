# 模型快捷切换：界面与排序说明

## 范围与方向

这是 DSH 里的高频模型选择工具，不是独立品牌页面。保留 DSH 的明暗主题、字体和原生选择控件，把**模型名称与位置编号**作为视觉主角；提供方、推理强度和内部 ID 退到辅助层，警告色只用于不可用和失败。

相关实现见[快捷列表](../client/src/01b-model-shortcuts.js)和[设置区](../client/src/13b-model-shortcut-settings.js)，不改变宿主模型状态来源，也不改变其他快捷键的保存方式。

## 界面与交互约束

- 快捷列表只列已配置模型，保留对应的 1–9 编号；当前项、焦点、加载中、切换中、空列表和不可用状态分别表达。
- 设置区保留全部 9 个位置，空槽不自动合并。模型选择和推理强度控件可直接操作；内部 ID 可以按需查看，不重复挤占主信息。
- 拖动从独立握柄开始，鼠标与触控均须超过阈值才启动；普通下拉框操作不触发拖动。移动的是完整槽位对象，模型与推理强度一起移动，数组长度和空槽数量不变。
- 松手后只保存一次，原位置松手不保存；Esc 或指针取消不保存。保存失败恢复原顺序并显示原因，不清空配置。握柄提供键盘排序替代。
- 排序只更新本机的模型快捷配置文件（`~/.dsh/model-shortcuts.json`），不实时广播，不提交或推送，也不含密钥。每台电脑一份；需要跨设备搬用时，在同步弹窗里单独勾选「模型快捷槽位」，推送写本机机器备份、拉取只读本机备份。快捷选模仍只作用于当前正在看的设备与对话。

## 最小动效与证据边界

1. 握柄和模型选项提供短促按下反馈，业务操作不等待动画。
2. 拖动目标通过插入位置高亮与颜色过渡表达新的编号映射。
3. 快捷面板提供 200ms 轻量入场；正常重新渲染不重复播放。

开启“减少动态效果”时状态直接到位。这三处已经落实到代码。实际视觉及动效须在已登录页面验收；未登录或独立截图不能代替。

## 验收重点

保留用户已保存的模型、强度和空槽；覆盖重排、无变化、取消、保存失败及键盘替代。标准构建后再运行完整回归，原有设备切换、输入保护、远端会话与插件导出契约不得回退。

独立截图或自动化浏览器不继承用户的登录态；如果现有 GUI 拒绝访问，记录该限制，并由用户在当前已登录页面复核，不创建替代应用或伪造实机证据。真实界面视觉、拖动手感和动效仍待已登录 GUI 中的人工验收。

## Kiro 边界

推理强度选项必须来自当前设备的宿主模型能力声明；没有声明时不凭模型名称补出档位。Kiro 的能力声明、参数转换和上游支持单独只读分析，修复提供方配置须在查清实际支持后另行确认。

## 已确认版式：B 紧凑双行

用户在三个版式对比后选择「紧凑双行」。[设置区](../client/src/13b-model-shortcut-settings.js)首行展示编号、模型选择和独立握柄；次行展示厂商、短推理强度框和清除。厂商配色不变，模型和档位的不可用说明保留在控件外，不拼进单行下拉框文字。

[样式](../client/src/02-styles.js)根据设置列表的实际宽度使用容器查询：宽度不足 520px 时将厂商另起一行，不足 360px 时将强度标签移到选择框上方。换行依据不是整个浏览器的宽度，宽窗口里的窄设置区也不会挤压控件。

[浏览器布局回归](../tests/model-shortcut-settings.test.mjs)使用实际组件输出和生产 CSS，覆盖 320、390、640、1280px 视口、1256px 下的 CSS 200% 显示，以及 1280px 窗口内的 420px 设置区；检查强度、厂商、清除与异常说明不重叠。

证据边界：浏览器截图为静态组件夹具，不是已登录 GUI，也不证明真实宿主的保存交互。保存、清除、排序、取消与失败恢复的原有逻辑未变。
