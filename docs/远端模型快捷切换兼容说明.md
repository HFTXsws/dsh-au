# 远端模型快捷切换兼容说明

## 已修复的责任层

模型触发键保存在本机的模型快捷配置文件（`~/.dsh/model-shortcuts.json`）。每台电脑一份，云端同步时各设备只读写自己的机器备份（`sync/machines/<machineId>.json` 的 `modelShortcuts` 字段）；旧版仓库共享配置只在首次升级时迁移一次，之后仅作回滚备份，不再被读取。桌面端使用宿主标准 `shortcuts.register` 命令声明，将本机键作为默认值接入原生 iframe 按键分发；不调用宿主偏好写入，不重置本地覆盖。只读 `registerFixed` 不能驱动这种原生分发，因此没有使用它代替命令注册。

如果用户另外在宿主设置里改了该命令的本地键位，功能会明确提示覆盖冲突，不把本地值写回项目，也不擅自清除覆盖。

受控端安装监听后主动索取配置；远端确认 ready 后再补发。远端 iframe 被识别为 web 时，只转发外层已经配置的模型键，不用远端网页保留键规则再次否决它。

## 旧远端选模

已有旧工作区快照协议的远端，通过“请求当前快照 → 带随机标记的 frame-probe 回执”确认真实可见会话，再通过官方统一 `/api` Remote 方法查询目录、选择模型。实际通路来自正在显示的 iframe，不按后台优选通路重选。

[后端兼容层](../lib/remote-model-shortcuts.js)只允许模型目录与选择两个方法，验证设备、通路、会话和响应；不会回退本机会话、另一个通路或其它模型。全局 catalog 的 default 不是该远端会话当前模型，旧协议缺少当前模型信息时不冒称“当前”。

新协议还校验列表世代和 iframe 文档标记，拒绝刷新、关闭或设备切换后的旧回复。数字只在外层模型列表打开时处理。

## 版本和验收边界

本机新增了远端模型 API，旧本机插件未重载时可能把未知 action 返回为普通状态快照；客户端会拒绝这种伪成功，明确要求重载插件或重启本机 DSH。

纯网页访问一个未安装模型键盘桥的跨域旧远端，浏览器不允许外层直接读取它的键盘事件，仍需更新该远端 DSH AU；不能把 HTTP 可达当成键盘已兼容。桌面原生接入也必须在真实远端输入框内验收。
