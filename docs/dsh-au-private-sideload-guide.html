🔌 DSH-AU 私人仓库侧载（Sideload）能力图解

开源插件 dsh-au 只做空插座（出厂零私有代码）；连接私人仓库后自动挂载以下 4 大能力（左侧均为真实 UI 实拍并对具体业务文字做了脱敏模糊，点击图片可放大查看）：

1主界面左侧栏分组 + 右侧大舞台

在 DSH 左侧「工作区」树直接挂入外部团队分组，点击子项即接管右侧主聊天区收发消息、预览日报与图片。

📁 私人仓库：dsh-sync/extensions/<目录>/extension.json 
{
  "id": "grokbot",
  "title": "GrokBot",
  "surfaces": ["sidebar"],
  "clientFile": "client.js",
  "serverFile": "server.js"
}

2工作台弹窗自定义页签

给工作台弹窗（Alt+9）左侧导航栏增加专属工具页签，用于放置私有的额度进度看板、Key 切换或内部配置面板。

📁 私人仓库：dsh-sync/extensions/<目录>/extension.json 
{
  "id": "my-dashboard",
  "title": "自定义额度与模型看板",
  "surfaces": ["workbench"],
  "clientFile": "client.js",
  "serverFile": "server.js"
}

3任意后台常驻服务托管

在机器绑定 JSON 中登记任意本地脚本（.py / .pyw / .ps1 / .sh）与端口，自动接管随 DSH 自启、开机自启、探活与一键启停。

📁 私人仓库：dsh-sync/machines/<machineId>.json 
"my_gateway": {
  "control": "full",
  "name": "本地模型网关",
  "scriptPath": "gateways/my-gateway/launcher.pyw",
  "health": "http://127.0.0.1:8322/health",
  "port": 8322
}

4自定义快捷脚本菜单（双系统自适应）

工作台内的序号指令全部从私人仓库 menu.json 读取，新增运维或额度脚本后即可按序号检索、收藏并双击运行。

📁 私人仓库：dsh-sync/menu.json 
{
  "code": "11",
  "label": "同步最新 Skill（含规则构建）",
  "win": "powershell -File scripts/init.ps1",
  "mac": "bash scripts/init.sh"
}
